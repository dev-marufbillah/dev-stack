# 🚀 DevStack - Build Your Ideal Development Stack

A modern web application to explore, compare, and build developer technology stacks.

## ✨ Features
- 🧭 **Sticky & Responsive Navigation:** Header stays fixed with mobile dropdown menu.
- 🎨 **Shared Brand Theme:** Unified gradient styles for consistent UI.
- 🧰 **Interactive Stack Builder:** Add or remove technologies with real-time feedback.
- ⚡ **Dynamic Data Loading:** Fetches tech data with loading spinner indicator.

## 🛠️ Tech Stack
- **Frontend:** React.js, Tailwind CSS
- **Build Tool:** Vite
- **Deployment:** Vercel / Netlify
